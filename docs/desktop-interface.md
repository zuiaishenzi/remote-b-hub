# 三页桌面界面

A、B 统一为深色左侧导航与浅色内容区，默认进入首页。原有配置目录与 DPAPI Token 格式不变，不必重新填写连接信息。本次为桌面界面升级，NAS 协议无需更新。

## 首页

B：首页集中启动/停止代理、启动 SolidWorks、检查状态、安全解除暂停与最小化驻留。状态卡展示代理、SW 和 NAS；运行详情显示当前阶段与任务 ID。SW 状态注明检查时间，NAS 公共健康接口可达与代理鉴权成功分别展示。

A：首页集中启动 Codex、CAD 管理、建模技能、SW 脚本和截图请求。B 在线状态每 10 秒刷新，自动轮询只使用已保存的连接信息，不会向正在编辑的地址发送凭据。SW 卡来自最近一次真实任务查询，不将 B 在线等同于 SW 已连接。

## 日志

支持关键字搜索、自动滚动、错误提示色、导出当前缓冲区和清空显示。清空显示不会删除磁盘日志，导出保留当前缓冲区的全部内容。B 原有日志轮转继续生效；A 的应用事件另存于配置目录 `client.log`，写入前脱敏。

A 的任务 ID 查询、错误信息、截图附件与查看入口位于日志页；首页保留当前任务的快捷查询。

## 设置

NAS 地址、Token、输出路径、模板、SW 程序、Interop、自动启动与脚本/截图权限按组集中管理。B 设置页可滚动，保存前仍需完成当前任务并停止代理。A 设置页可选择仓库工作目录。检查更新与打开日志目录均保留。

## 图标与兼容

使用自行绘制的几何连接立方体图标：A 为蓝色，B 为青绿色。应用窗口、任务栏和 EXE 使用统一图标，并提供 16–256 像素 Windows ICO 尺寸。

源码位于 `scripts/generate-desktop-icons.py`，资源位于 `assets/`。打包时将图标与资源内置，移动单个 EXE 不会丢失图标。

构建检查覆盖原有代理生命周期、GUI 与更新流程，并增加页面切换保留设置、日志筛选/脱敏、自动轮询使用已保存凭据、设置页滚动和 ICO 尺寸测试。界面视觉检查使用隔离配置，不操作用户的 SW 模型。
